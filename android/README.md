# 校园网自动连接 · Android 版

适用于 **Android 8.0 及以上**，默认面向中原工学院 **zut-stu + 中国联通**。当前版本为 1.0，包名 `cn.zhuidev.campus`，编译 / 目标 API 为 36。

[下载 APK](./校园网自动连接-安卓.apk?raw=true) · [下载完整源码](./安卓源码.zip?raw=true)

## 安装和第一次连接

1. 将 `校园网自动连接-安卓.apk` 下载到手机，打开后按系统安装提示完成安装。
2. 先在手机系统 Wi-Fi 设置里连接 **zut-stu**，并允许手机保持连接这个暂时未联网的 Wi-Fi。
3. 打开应用，输入学号 / 账号和校园网密码，运营商默认 **联通**。
4. 点击 **Wi-Fi 识别授权**，允许精确位置。Android 将 Wi-Fi 名称归为位置相关信息；应用只读取已连接的 Wi-Fi 名称，不调用 GPS 坐标。部分系统还要求打开手机的定位开关。
5. 点击 **保存并连接**，等待窗口显示“校园 Wi-Fi 的互联网检测已通过”。

第一次后仍未联网时，应用会进行第二次尝试，每轮最多提交两次。识别到认证失败、密码错误、欠费或验证码要求时会停止，并暂停自动任务。出现验证码时，使用 **查看学校登录页** 手动完成。

之后打开应用，可使用已保存的账户自动尝试登录。账号在应用私有目录保存，密码使用 Android Keystore 管理的 AES-GCM 密钥加密；关闭系统备份，不向开发者或 GitHub 上传账号和密码。

## 后台与定时功能

后台功能默认关闭，勾选所需选项后保存即可启用：

- **后台断线检测**：最短配置间隔为 15 分钟，实际执行时间由 Android 决定。省电、休眠、厂商后台限制可能使检查延后。应用留在前台时，开启此项后约每分钟检查一次。
- **每日定时尝试**：是系统调度的近似时间，不保证精确到分钟。不会强制唤醒屏幕，也不会在后台弹出界面。
- **重启后恢复**：恢复已经启用的后台任务；不是开机后立即打开应用。手机必须先解锁，系统也可能延后执行。
- **通知**：启用后台功能时可授予通知权限，用于提示需要检查账号或权限的情况。
- **后台 Wi-Fi 识别**：部分 Android 版本要求将应用位置权限设为“始终允许”并开启系统定位。可通过应用内 **后台运行与权限说明 → 打开应用设置** 查看本机选项。没有所需权限时，任务会跳过，不向未知网络提交账号。
- **停止**：点击 **停止本次及后台任务** 可取消当前连接并暂停自动任务；再次保存或手动连接可恢复。

应用被用户在系统中强制停止后，Android 通常不会继续执行任务，需重新打开应用。各品牌的“自动启动”“后台运行”“电池优化”等菜单不同，本版本没有特定品牌的强制保活逻辑。

Android 10 及以上对 Wi-Fi 控制存在限制，因此本应用提供系统 Wi-Fi 设置入口，需要先由系统连接到 zut-stu，不尝试静默切换任意网络。参见 [Android Wi-Fi 限制说明](https://developer.android.com/about/versions/10/privacy/changes#enable-disable-wifi)。后台任务的时间限制参见 [JobInfo.Builder](https://developer.android.com/reference/android/app/job/JobInfo.Builder)。

## 登录和检测方式

通过系统 WebView 操作学校原登录页，不需要另装浏览器。已从学校网页核对字段 `DDDDD`、`upass` 及联通选项 `@unicom`。不固定截图中的用户 IP，由校园网登录页提供当前设备参数。

登录与联网检测明确选择 Wi-Fi 网络，避免把移动数据已经联网误判成校园网登录成功。程序会临时将本应用的网络连接绑定到该 Wi-Fi，结束后恢复；不切换手机移动数据开关。

检测请求访问百度 robots.txt 和微软网络检测文本；两者都不可访问时可能误判为未联网。学校修改登录页或网关地址后，可能需要更新适配。

## 排查

- 无法读取 Wi-Fi：检查精确位置权限、系统定位开关，以及当前是否确实连接 zut-stu。
- 后台没有及时执行：先打开应用测试手动登录，再检查后台权限；系统调度并不保证实时重连。
- 提示认证失败：在学校登录页核对账号、密码、联通选项和账号状态。
- 提示两次后仍未联网：用 **查看学校登录页** 查看学校的具体提示。若学校移动端或 WebView 行为不同，需要根据实机结果调整。

排查时可复制状态日志发给开发者；应用日志不记录账号、密码、认证请求或完整网页内容。

## 验证范围

已完成 Android Java 编译、DEX 打包、APK 对齐与 v2 / v3 签名校验，24 项 JVM 核心逻辑测试和 12 项桌面浏览器登录页模拟检查通过。

**尚未在 Android 真机或模拟器中安装运行，也没有进行真实校园网账号登录。** 因此安装兼容性、系统 WebView 行为、后台 JobService 中的网页登录和厂商后台权限仍需实机确认。APK 属于可试用初版，不表示已经验证了锁屏后台重连。

## 源码和构建

`安卓源码.zip` 内的 `project` 是原生 Java Android 项目，无第三方运行时依赖。可用 Android Studio 打开；Gradle 配置为 AGP 8.10.1，需配套 Gradle 8.11.1 及兼容 JDK、Android SDK 36。源码包未包含 Gradle Wrapper、SDK 或签名私钥。

Windows 上也可以使用 SDK Build Tools 36.0.0、Android SDK 36 的 `android.jar` 和 JDK 17 / 21，执行附带脚本构建，无需 Gradle：

```powershell
.\build-apk.ps1 -AndroidJar '你的SDK\platforms\android-36\android.jar' -BuildTools '你的SDK\build-tools\36.0.0'
```

默认在 `.local-signing` 创建本地测试密钥，此目录已被忽略。若需复用自己的签名，可在构建前设置 `CAMPUS_KEYSTORE` 和 `CAMPUS_KEYSTORE_PASSWORD`；别名为 `androiddebugkey`。签名不同的 APK 不能直接覆盖安装同包名应用；自行构建时请保留自己的签名密钥。

JVM 核心测试源码位于 `project/tests/CoreTests.java`。登录表单模拟检查在桌面 Edge 中执行，只用于验证脚本的字段选择、转义、准备 / 提交步骤和错误停止，不代替 Android 实机测试。
